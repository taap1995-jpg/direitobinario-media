# @direitobinario — campanha social
Fontes editáveis e roteiro de geração das peças da campanha de outubro de 2026.

- Leia `ROTEIROS-E-LEGENDAS.md` para texto e fontes jurídicas.
- O workflow do GitHub Actions gera JPGs 1080×1350 para Feed, JPGs 1080×1920 para Stories, MP4s verticais para Reels e locução sintetizada em português.
- Os arquivos finais ficam em `campanha-outubro-2026/gerados/` após a execução do workflow.
- Nenhum arquivo é publicado no Instagram automaticamente.
